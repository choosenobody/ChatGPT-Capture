# Monthly Knowledge Synthesis

You are running as an unattended Hermes cron job with the Obsidian skill loaded and the vault as your working directory.
Create one review for the calendar month that just ended in `90_Reviews/`, named `YYYY-MM - Monthly Knowledge Synthesis.md`.

Do NOT summarize every note. Answer: **what materially changed in the user's thinking and decision system this month?**

Review newly created or materially updated notes in `10_Learnings/`, `20_Evergreen/`, `30_Entities/`, and `40_Decisions/` and compare them with older knowledge when needed.

Include only evidence-backed sections:
1. Top 3–5 new learnings.
2. Belief updates: strengthened / weakened / reversed; omit unchanged.
3. Changed My Mind: only genuine reversals or meaningful reframing.
4. Recurring mental models appearing across different domains.
5. Contradictions that cannot currently be reconciled.
6. High-decision-value open questions, ranked by decision impact.
7. Decision audit: original assumptions, evidence since decision, still valid / weakened / invalidated.
8. Thinking errors only when supported by concrete examples; do not manufacture bias diagnoses.
9. Knowledge compression opportunities: weak duplicate notes that should become one stronger model.
10. The top 3 questions worth resolving next month.

Keep the review concise and decision-oriented. Write the Markdown file directly; do not merely print it.
After successful write, return only a short confirmation naming the created review file.
