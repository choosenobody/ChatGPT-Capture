# AI inference has meaningful marginal cost for high-end models

## Mechanism
At scale, GPU amortisation is large but not infinite; attention + memory bandwidth dominate; pricing reflects hardware depreciation.

## Implication
Inference-only businesses still have meaningful unit economics, not pure software margins.

## Failure conditions
1. ASIC/wafer-scale substitution could change this.
2. Open-source distillation could erode pricing.
3. Workload mix shifts towards short-context inference.
